# Windows 30–45 秒录屏脚本

> 用 OBS 的 Windows Graphics Capture 录屏，录屏范围包含桌面 + 记事本 + 宠物。
> Unity Personal 的启动 Splash 不能关闭，先启动宠物、等 Splash 结束再开始录。

| 时间 | 操作 | 期望画面 |
|---|---|---|
| 0–3s | 桌面右下角出现透明宠物，背景透出桌面 | 无黑底、无边框、无任务栏图标 |
| 3–8s | 打开记事本，输入 `abc`，点击宠物，再输入 `def` | `def` 仍进入记事本，宠物不抢焦点 |
| 8–13s | 点击宠物旁边的透明空白（覆盖记事本） | 记事本光标移动/可选中文本，宠物不响应 |
| 13–20s | 把宠物拖到记事本窗口顶边松手 | 宠物圆盘底边贴住顶边 |
| 20–30s | 上下左右拖动记事本 | 宠物实时跟随，无分离 |
| 30–36s | 最小化记事本 | 宠物平滑落回桌面；再点宠物有闪烁/小跳反馈 |
| 36–42s | 恢复记事本，重新吸附，关闭记事本 | 宠物再次落回桌面，无报错 |
| 42–45s | 按 `Ctrl+Alt+Q` | 进程退出，任务管理器无残留 |

## 一镜到底检查点

- 透明区域能看到并操作底层窗口
- 宠物本身可点/可拖，但不抢前台输入焦点
- 顶边吸附、跟随、最小化/关闭落回三件事连续完成
- 落回后点击宠物仍有反馈
- 退出干净
