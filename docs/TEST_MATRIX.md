# M0 真机测试记录表

## 测试环境

| 项 | 值 |
|---|---|
| 操作系统 | Windows 11 build 26200（单显示器 1536×864 @125%） |
| 硬件 | 单屏；无第二显示器 |
| Unity | 2022.3.62f3c1 LTS（Built-in，仅 D3D11） |
| 构建 | Windows x64 Mono，`Build\Windows\xiaosu-pet.exe` |
| 录屏 | OBS Windows Graphics Capture（待录） |
| macOS | 无机器，阻塞 |

## Windows 用例

| # | 用例 | 结果 | 备注 |
|---|---|---|---|
| 1 | 启动后背景完全透明、无黑底/边框/任务栏项 | 通过 | 全屏截图可见桌面；`WS_EX_TOOLWINDOW` 无任务栏项 |

| 5 | 点透明空白可点穿到记事本/桌面图标 | 通过 | `WindowFromPoint` 圆盘外返回下层窗口，宠物无日志 |
| 6 | 拖到记事本顶边松手吸附 | 通过 | 日志 `attached to class=Notepad` |
| 7 | 拖动记事本时宠物逐帧跟随 | 通过 | 记事本 +100,+50，宠物窗口同步 +100,+50 |
| 8 | 横向缩放记事本时宠物仍在顶边 | 通过 | 800→600 宽，宠物顶边不动 |

## 暂不支持

- 独占全屏游戏 / 独占全屏视频
- 最大化窗口顶边（宠物无法坐到屏幕外）
- cloaked / 挂起的 UWP 特殊窗口、虚拟桌面切换
- 跨混合 DPI 显示器的窗口
- macOS（源码已交付，未编译/未实测）
